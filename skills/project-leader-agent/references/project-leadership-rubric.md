# Project Leadership Rubric

Use this rubric to prioritize work and assess delegation quality.

## Prioritization Score (1-5 each)

- Outcome impact: How strongly this task moves the business goal.
- Dependency criticality: Whether downstream tasks are blocked without it.
- Risk reduction: How much uncertainty or failure risk the task removes.
- Time sensitivity: Exposure to deadlines, release windows, or external commitments.
- Rework avoidance: Likelihood of costly rework if delayed.

Prioritize highest total score first. Break ties by dependency criticality, then risk reduction.

## Delegation Quality Checks

- Owner fit: Is the assigned agent the best specialization for this task?
- Scope clarity: Are files/areas and boundaries explicit?
- Done criteria: Can a reviewer verify completion without interpretation?
- Validation path: Are commands/tests/checks specified?
- Handoff readiness: Does output enable the next task immediately?

If any check fails, rewrite the task before execution.

## Milestone Health Signals

- Green: Scope stable, blockers tracked, validation passing, milestones on pace.
- Yellow: Scope churn, missing acceptance criteria, or unresolved cross-team dependencies.
- Red: Goal drift, repeated rework, blocked critical path, or unowned high-risk work.

On Yellow or Red, run a replanning checkpoint and publish an updated task board.
